# Test results (v4)

All results are from the final build (`node build.mjs`). Probe pages were
generated by `node qa.mjs <dir>` into a scratch directory, not shipped. Each
probe injects one script into a copy of a built page:

- head probes run before the pre-paint script: they seed, clear or block
  storage;
- body probes run after load: they open the panel, audit, or exercise the
  controls.

Rendering used a sandboxed preview frame at fixed widths with an auto height.
Its `appearance` parameter sets `prefers-color-scheme`.

## Functional

**Exercise** (`home.exercise`): the probe clicks the toggle, picks all six
values through the form, reads storage, resets, then reopens and presses Escape.

```json
{"stored":"{\"theme\":\"dark\",\"ink\":\"sakura\",\"read\":\"serif\",\"size\":\"large\",\"density\":\"compact\",\"motion\":\"reduced\"}",
 "applied":"dark,sakura,serif,large,compact,reduced","status1":"",
 "afterReset":null,"appliedReset":"system,ai,sans,standard,comfortable,system",
 "status2":"back to the defaults.","wasOpen":true,"escClosed":true,"focusBack":"appearance-toggle"}
```

**Denied storage** (`home.deny`): the `localStorage` getter throws
`SecurityError`, and the same steps run.

```json
{"stored":"THREW SecurityError","applied":"dark,sakura,serif,large,compact,reduced",
 "status1":"this browser isn't keeping settings, so they'll reset on reload.",
 "afterReset":"THREW SecurityError","appliedReset":"system,ai,sans,standard,comfortable,system",
 "status2":"back to the defaults for this visit.","wasOpen":true,"escClosed":true,"focusBack":"appearance-toggle"}
```

The controls still apply for the visit, and the status line says why they won't
persist. The status uses `role=status`.

**Invalid stored JSON** (`bogus`: `{"theme":"vellum","ink":"coral","size":9`,
truncated): the pre-paint script's try/catch ignores it and renders defaults.

**Persistence across pages and reload (real browser):**

- Setup: an incognito preview tab, served by a temporary loopback static server
  (`127.0.0.1:8765`, stopped afterwards).
- On home.html the settings were set to dark, sora, serif, large, compact and
  reduced.
- After navigating to about.html:
  - background `rgb(21, 24, 29)`;
  - prose family Lora;
  - root font size 18px;
  - all six radios checked to match.
- A reload kept them. Reset cleared the `appearance` key.
- No requests other than the page itself.

## Not tested, or tested only partly

- **Real keyboard traversal:** not run. The preview tool's Tab key produced no
  focus events in the hidden tab. Focus was tested with programmatic `.focus()`,
  `:focus-visible` matching, and a synthetic Escape `keydown` dispatched on
  `document`.
- **Real pointer input:** not run. Preview clicks timed out, so the probes use
  DOM `.click()`. The outside-pointerdown close is covered by code review only.
- **OS-level reduced motion:** not emulated. The `data-motion=reduced` path was
  probed, and the media query gating was reviewed in code.
- **Screen readers:** not tested.
- **Fixed bottom sheet at ≤30em:** in an auto-height capture it is placed
  against the frame, not a phone viewport, so the 390 settings-open shots show
  its contents but not its true position.
