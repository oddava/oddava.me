# oddava.me

this site is an experiment in keeping a public memory — notes, projects, and
half-finished questions in one place that links back to itself.

it's closer to a workshop than a portfolio, and i'd rather it stay that way.

it's built with astro and typescript and lives on cloudflare. the code is
[on github](https://github.com/oddava/oddava.me) if you feel like poking around.
