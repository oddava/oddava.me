# Font provenance

All intended primary and selectable reading fonts are free under **SIL Open Font License 1.1**. The licence texts are included beside these files. Font bytes are embedded in every applicable HTML file; viewing the mockups requires no font download.

| Font                                        | Role                                                      | Bytes / provenance                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------- | --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Public Sans, variable 100–900               | Margin and Parts Desk primary sans; comparison page       | Unmodified `PublicSans-variable.ttf`, downloaded from [Google Fonts' official Public Sans directory](https://github.com/google/fonts/tree/main/ofl/publicsans). Copyright 2015 The Public Sans Project Authors. `PublicSans-OFL.txt`.                                                                                                                                                                                                                                                                                                                                                                    |
| JetBrains Mono, regular 400                 | Metadata, file paths, route/page labels                   | Repository `public/fonts/jetbrains-mono-latin-400-normal.woff2`, copied here and embedded. [Official Google Fonts licence](https://github.com/google/fonts/blob/main/ofl/jetbrainsmono/OFL.txt), copyright 2020 The JetBrains Mono Project Authors. `JetBrainsMono-OFL.txt`.                                                                                                                                                                                                                                                                                                                             |
| M PLUS Rounded 1c, regular 400 and bold 700 | Walking Index primary sans                                | Repository `public/fonts/m-plus-rounded-1c-latin-{400,700}-normal.woff2`, copied here and embedded. Copyright 2016 The Rounded M+ Project Authors. Current [Google Fonts metadata](https://github.com/google/fonts/blob/main/ofl/mplusrounded1c/METADATA.pb) identifies OFL; copy retained as `MPLUSRounded1c-METADATA.pb`. The Google Fonts directory currently lacks an OFL text file, so `MPLUSRounded1c-OFL.txt` is the matching licence distributed in the [Fontsource package](https://www.npmjs.com/package/@fontsource/m-plus-rounded-1c), retrieved from its npm tarball without installing it. |
| Lora, variable 400–700                      | Optional serif reading preference, not default brand type | Unmodified `Lora-variable.ttf`, downloaded from [Google Fonts' official Lora directory](https://github.com/google/fonts/tree/main/ofl/lora). `Lora-OFL.txt`. Loads only when requested; renderer QA explicitly loads and checks it.                                                                                                                                                                                                                                                                                                                                                                      |

Arial, Helvetica and Georgia appear only as emergency fallback names, not packaged fonts and not claimed to be freely licensed fonts. Renderer QA confirms intended faces loaded. System sans/serif and emoji are not a deliberate asset dependency. No font file was converted or modified; Latin subsets already in the repository are used as-is.
